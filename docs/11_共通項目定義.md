# 共通項目定義：電車ルート検索アプリ

作成日：2026-11-18／位置づけ：ストレージキー、インデックス定義、コード値の「正」は本書とする。他文書は本書を参照し、値を重複定義しない。

## 1. ストレージキー定義（localStorage）

| キー | 値の形式 | 内容 | 初期値 |
|---|---|---|---|
| tra.usage | JSON: { "month": "YYYY-MM", "count": number } | 月間リクエストカウンター | { month: 現在月, count: 0 } |
| tra.history | JSON 配列（最大 10 件、新しい順） | 検索履歴（出発地・目的地・出発オフセット） | [] |
| tra.settings | JSON: { "warnAt": number, "stopAt": number } | 警告／停止の閾値 | { warnAt: 8000, stopAt: 10000 } |
| tra.originText | string | 出発地の前回入力値 | "" |

## 2. インデックス定義

本アプリは RDB を持たないため、物理インデックスは「アクセスキー」として本節に定義する。他文書（docs/05、docs/06）はこの定義を参照する。

| # | 対象ストア | インデックス（アクセスキー） | 生成方法 | 用途 |
|---|---|---|---|---|
| IDX-01 | サーバー側メモリキャッシュ（Map） | キャッシュキー文字列 | cacheKeyFor: SearchParams を stableStringify（キー順非依存の JSON 文字列化）した値 | 同一条件の再検索を 60 秒間キャッシュから返す |
| IDX-02 | localStorage tra.usage | month（YYYY-MM、Asia/Tokyo） | monthKey(date) | 月間カウンターの月判定。現在月と異なる場合は新規レコード相当として扱う |
| IDX-03 | localStorage tra.history | 配列の並び順（先頭が最新） | 追加時に先頭へ挿入し、11 件目以降を末尾から削除 | 履歴プルダウンの表示順 |

制約：

- IDX-01 の有効期間（TTL）は 60 秒。失効したエントリは取得時に削除する。
- IDX-02 は一意であり、tra.usage 内に月は 1 件だけ保持する（過去月は保持しない）。

## 3. コード値

### 3.1 エラーコード（ApiErrorCode）

| コード | HTTP | 意味 |
|---|---|---|
| API_KEY_NOT_SET | 503 | サーバーに API キーが未設定 |
| UPSTREAM_ERROR | 502 | Routes API 側のエラー |
| NOT_FOUND | 404 | ルート 0 件 |
| INVALID_PARAMS | 400 | 入力不正 |
| LIMIT_REACHED | （画面側で生成） | 月間上限到達。API は呼ばない |

### 3.2 並び替えモード（SortMode）

| 値 | 表示 | 意味 |
|---|---|---|
| recommend | 総合おすすめ | スコア順（運賃 0.4／所要時間 0.3／乗り換え 0.3） |
| fare | 最安 | 運賃が確定した候補の中での最安順 |
| transfers | 乗り換え最少 | 乗り換え回数の昇順 |
| duration | 最短 | 所要時間の昇順 |

### 3.3 上限判定（LimitStatus）

| 値 | 条件 | 画面の扱い |
|---|---|---|
| ok | count ＜ warnAt | 通常表示 |
| warn | warnAt ≦ count ＜ stopAt | 残量の警告を表示 |
| stop | stopAt ≦ count | 検索を止め LIMIT_REACHED を表示 |

## 4. 環境変数

| 変数 | 用途 | 備考 |
|---|---|---|
| GOOGLE_MAPS_API_KEY | Routes API のキー | サーバー側のみ。画面・応答へ出さない |
| TRA_USE_MOCK | キー無し開発時のモック利用 | "1" のとき有効 |
