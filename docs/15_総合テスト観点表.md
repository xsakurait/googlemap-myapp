# 総合テスト観点表

要件定義（`docs/00`）と非機能の観点から、結合・総合レベルで確認する項目を整理する。単体テストで担保する項目は対象外とし、起動・連携・実環境に寄るものだけを扱う。

## 観点項目

| ID | 項目 | 観点 | 実施環境 |
| --- | --- | --- | --- |
| ST-01 | 起動とトップ表示 | standalone ビルドでサーバーが起動し、トップ画面が 200 で返ること | 実行環境 |
| ST-02 | Docker 起動 | `docker compose up` で起動し、トップ画面が表示できること | 本人 PC |
| ST-03 | モック検索フロー | モック指定の検索で候補が返り、画面表示用データが揃うこと | 実行環境 |
| ST-04 | キー未設定時の応答 | API キーが無い状態の検索は 503（API_KEY_NOT_SET）になること | 実行環境 |
| ST-05 | 不正リクエスト | JSON でないボディは 400（INVALID_PARAMS）になること | 実行環境 |
| ST-06 | env の読み込み | `.env.local` のキーがサーバーに渡り、上流 API へ到達すること | 実行環境 |
| ST-07 | 実キー検索 | 実キーで実際のルートが返ること（無料枠の消費は最小限） | 本人 PC |
| ST-08 | GPS 実機確認 | 実機ブラウザで現在地が取得でき、出発地に使えること | 本人環境 |
| ST-09 | 無料枠ガードの画面連動 | 利用件数の表示、警告・停止の切り替わりが画面に出ること | 本人環境 |
| ST-10 | V-01 バスの収録確認 | Routes API（TRANSIT）で東京〜大阪等の高速・夜行バスが返るか（要件定義 §10.10） | 本人 PC（キー必要） |
| ST-11 | V-02 飛行機の無料 API 確認 | SerpApi 無料プラン等で国内線の運賃目安が取れるか（要件定義 §10.10） | 登録後 |
| ST-12 | 画面操作の一連 | 並び替え切替、履歴からの再検索、モック表示の切り替えが操作できること | 本人環境 |

## 進め方

- 実行環境で実施できる項目（ST-01、ST-03〜ST-06）を先に実施し、結果を `docs/16_総合テスト結果.md` に記録する。
- 本人環境・キー・登録が必要な項目は、環境が揃った時点で実施し、結果を追記する。
