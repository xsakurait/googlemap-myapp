# 単体テスト観点表

単体テストの観点をモジュール単位で整理する。テスト ID（UT 番号）はファイル（モジュール）単位で採番する。実施結果は `docs/14_単体テスト結果.md` に記録する。

## 観点の分類

- 正常：仕様どおりの入力で期待どおりの結果になること
- 異常：不正な入力・エラーを、決められたエラー形式で返せること
- 境界：上限・下限・同点・空など、境目で誤判定しないこと
- 構造：並び替えの同点処理（タイブレーク）やフォールバック経路を通すこと

## 対象外（単体テストでは扱わない）

- 画面の見た目・操作（コンポーネント）は総合テストと目視確認の対象とし、カバレッジ対象からも外している（`docs/12` の方針どおり、対象はロジック層と API）。
- 実 API キーを使った疎通、GPS の実機確認は総合テストの対象。
- バス・飛行機拡張の検証（要件定義 §10.10 の V-01／V-02）は総合テストで実施する。
