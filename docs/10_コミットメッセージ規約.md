# コミットメッセージ規約

本プロジェクトのコミットメッセージは、必ずプレフィックスを付けて1行で書く。

## 形式

```
<prefix>: <要約>
```

- 要約は1行で、変更内容が分かるように書く（日本語可）。
- 詳細が必要な場合は、空行を挟んで本文に書く。

## プレフィックス一覧

| prefix | 用途 | 例 |
|---|---|---|
| feature | 新機能の追加 | `feature: ルート概要のテキスト表示を追加` |
| fix | バグ修正 | `fix: 運賃不明ルートが最安表示になる問題を修正` |
| docs | ドキュメントのみの変更 | `docs: 要件定義書にプルダウンUIの仕様を追加` |
| refactor | 挙動を変えないコード整理 | `refactor: 並び替え処理を lib/ranking に分離` |
| test | テストの追加・変更 | `test: ranking の同点ケースを追加` |
| style | 書式のみの変更（動作に影響しない） | `style: Prettier の整形を適用` |
| chore | ビルド設定・依存関係・その他の雑務 | `chore: Vitest を 3.2 に更新` |

## ルール

- 1コミット = 1つの変更目的。異なる目的の変更はコミットを分ける。
- プレフィックスは上記から最も合うものを1つだけ付ける。
- 要約の末尾に句読点は付けない。
